# Projects

## Aeternum

Aeternum API is a cloud-based API testing service that allows users to define expected responses
for various endpoints and automatically verify them. Designed for scalability and reliability,
it supports concurrent request execution and real-time reporting.

Learn more at the [Aeternum documentation](https://jgfranco17.github.io/aeternum-api/).

## Fizzbuzz API

One of my early projects (dubbed "FizzBuzz-as-a-Service") which showcases the software engineering
and DevOps concepts I'd learned early into my journey in software development. This includes CI/CD
workflows, unit testing, and containerization. It provides a FastAPI-based microservice that solves
the\ classic FizzBuzz problem via a REST API, with deployment through Render for free hosting.

To try it out yourself, check out the [Fizzbuzz API docs](https://fizzbuzz-api.onrender.com/docs)!
