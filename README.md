# Personal Portfolio

My personal portfolio website.

## Setup

To get started on adding pages, first configure your dev environment.

```bash
# Clone repository
git clone -o personal-portfolio git@github.com:jgfranco17/portfolio.git
cd personal-portfolio

# Run setup script to facilitate configuration
./setup/install-dependencies.sh
```

## Adding Pages

To add a new page, a new Markdown file must be created in the `docs/` directory.
Don't forget to add new pages to the navigation in the `mkdocs.yaml` file.
